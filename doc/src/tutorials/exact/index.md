title: Exact computation
short: Exact
summary: Programs that compute with algebraic and exact real and complex numbers.
order: 6
---

These tutorials compute with exact real and complex numbers and
algebraic numbers ([](qqbar)): proving identities between elementary
constants, arithmetic in number fields, exact linear algebra, and
deciding equalities between large algebraic expressions. Each follows
one or two of the
[example programs](tutorials/getting-started/example-programs#exact),
which are written for the legacy [](ca) interface and run the same
computations in castle arithmetic ([](gr_ca)) with the flag `-castle`;
the tutorials show the `ca` code and compare the two. The guides
[](gr_ca/using), [](ca/using) and [](qqbar/using) introduce the
programming interfaces, and [](guide/types/choosing#exact) gives an
overview.
